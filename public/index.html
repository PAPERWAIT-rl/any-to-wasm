any‑to‑wasm

Upload a .zip of a project, or point at a public GitHub repo. We'll detect the language, compile it to WebAssembly where we can (Rust, and best-effort Go/C/C++), or run it in-browser via a WASM runtime (Python via Pyodide), package it as a static HTML/CSS/JS(+WASM) site, and hand you a zip you can host anywhere.

Public repositories only, cloned at --depth 1.
